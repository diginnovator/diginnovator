### Mahmood — building [CodeSky](https://codesky.ai)

I work on making software buildable in Arabic.

[**CodeSky**](https://github.com/codesky-ai) is an AI development platform where
you describe an application in Arabic or English and get a real one back —
planned before it is written, built across a full stack, previewed live while it
repairs its own build errors, and deployed to infrastructure you control. The
source is yours to download, sync and host anywhere.

Most of what I build lives under [**@codesky-ai**](https://github.com/codesky-ai).

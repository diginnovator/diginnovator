**CodeSky is an Arabic-first AI development platform.** You describe what you
want — in Arabic or in English — and it plans the application, writes it across
a real stack, previews it live while it fixes its own build errors, and deploys
it to infrastructure you control.

The code is yours. Download it, push it to your own Git remote, host it
anywhere. Nothing is locked to the platform.

```
وصف بالعربية  →  خطة  →  كود  →  معاينة حيّة  →  نشر على خوادمك
```

### What that means in practice

| | |
|---|---|
| **Plan first** | Your idea becomes a real requirements document — objectives, requirements, acceptance criteria — before any code exists |
| **Built, not scaffolded** | A working front end, back end and database, in frameworks you chose |
| **Live preview** | It runs while you build, and repairs its own build failures |
| **Yours to keep** | Full source download, Git sync, deploy to your own servers |
| **Bilingual throughout** | The product and the apps it generates are English and Arabic, with first-class RTL |
